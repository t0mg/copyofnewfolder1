# About copyofnewfolder1 game recs

copyofnewfolder1 is a bot that posts short indie video game reviews written by a friend of the [maintainer](https://bsky.app/profile/tomgranger.bsky.social) of this site.

Reviews were initially posted on [Bluesky](https://bsky.app/profile/copyofnewfolder1.bsky.social) and [Mastodon](https://mastodon.social/@copyofnewfolder1) and are now also available as a searchable archive here.

Browse the archive from the sidebar on the left, or jump to a year's index:

- [2026](recs/2026.md)
- [2025](recs/2025.md)
- [2024](recs/2024.md)

### Serverless markdown microblogging

This microblog is built with [Yodelog](https://github.com/t0mg/yodelog), a github template that automatically posts messages on Bluesky and Mastodon, and can deploy a Docsify minisite like this one, all from markdown files.
