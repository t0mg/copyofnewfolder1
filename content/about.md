# About copyofnewfolder1 game recs archive

copyofnewfolder1 is a microblogging bot that posts short indie game reviews written by a friend of the [maintainer](https://bsky.app/profile/tomgranger.bsky.social) of this site. Reviews were initially posted on [Bluesky](https://bsky.app/profile/copyofnewfolder1.bsky.social) and [Mastodon](https://mastodon.social/@copyofnewfolder1) and are now available as an archive here.

This microblog is built with [Yodelog](https://github.com/t0mg/yodelog), a github template that automatically posts messages on Bluesky and Mastodon, and can deploy a Docsify minisite like this one, all from markdown files.
